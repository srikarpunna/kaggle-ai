## PRODUCTION NOTES

### Recording Setup

**Tools Needed:**
1. Screen recorder (OBS Studio or Loom)
2. Voiceover microphone (clear audio essential)
3. Video editing software (DaVinci Resolve, iMovie, or Premiere)
4. Stock footage (optional, for elderly person clips)

### Screen Recording Checklist

- [ ] Set browser to full screen (no tabs/bookmarks visible)
- [ ] Clear screen resolution (1920x1080 minimum)
- [ ] Hide desktop icons, close unnecessary apps
- [ ] Test voice input beforehand
- [ ] Have demo data pre-loaded (Margaret Thompson profile)
- [ ] Practice the flow 3-5 times before recording

### Voiceover Tips

1. **Pace:** Speak clearly at ~150 words/minute
2. **Tone:** Professional but warm, enthusiastic but not salesy
3. **Pauses:** Pause 1 second at section breaks
4. **Emphasis:** Stress key numbers (52 million, 9.5/10, $39B)
5. **Ending:** Confident and inspiring close

### Editing Checklist

- [ ] Add fade transitions between sections (0.5s)
- [ ] Highlight key UI elements (zoom/circle)
- [ ] Add subtle background music (low volume, non-distracting)
- [ ] Include captions/subtitles for accessibility
- [ ] Final export: 1080p, MP4, H.264 codec
- [ ] File size: <100MB (upload to YouTube/Vimeo)

### Visual Enhancements

**Text Overlays:**
- Use large, readable fonts (32px+)
- White text on dark background (high contrast)
- Animate text appearance (fade in)
- Keep on screen 3-5 seconds

**Highlighting:**
- Circle important UI elements in red or yellow
- Zoom in on key features (2x zoom, smooth transition)
- Slow-motion for critical moments (button appear/click)

**Color Coding:**
- Green: Success, positive stats
- Blue: User actions, listening state
- Purple: AI thinking/processing
- White: Clean, accessible design

### Music Suggestions

**Background Track:**
- Genre: Soft ambient, inspirational
- Mood: Hopeful, warm, professional
- Volume: -20dB (quiet, not distracting)
- Examples:
  - "Inspiring Corporate" (free on YouTube Audio Library)
  - "Soft Piano Background" (calm, professional)

**No music during:**
- Live demo sections (voice commands should be clear)
- Voiceover with key statistics (keep focus on words)
